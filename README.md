# NoteBox セットアップ手順

個人用のノートアプリです。データは自分のGoogleドライブ「NoteBox」フォルダに保存され、同じURLを開いた端末どうしで同期します。サーバー不要で、GitHub Pagesに置くだけで動きます。

## 1. GitHub Pagesに公開する

1. GitHubで新しいリポジトリを作成（例：`notebox`）
2. このフォルダの全ファイルをアップロード
   `index.html` / `sw.js` / `manifest.webmanifest` / `icon.svg` / `icon-192.png` / `icon-512.png`
3. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存
4. 数分後、`https://<ユーザー名>.github.io/notebox/` で開けるようになります

> コードは公開されますが、ノートの中身は自分のGoogleドライブにあり、ログインしない限り誰も読めません。クライアントIDも秘密情報ではありません。

## 2. Google Cloud でクライアントIDを作る（初回だけ）

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成
2. **APIとサービス → ライブラリ** で「Google Drive API」を検索して **有効にする**
3. **OAuth同意画面**（画面によっては「Google Auth Platform」）を設定
   - ユーザーの種類：**外部**、アプリ名：NoteBox、メールアドレス：自分
   - **対象（Audience）→ テストユーザー** に自分のGmailアドレスを追加
   - **データアクセス（スコープ）** に `https://www.googleapis.com/auth/drive.file` を追加
4. **認証情報（Clients）→ OAuth クライアントIDを作成**
   - 種類：**ウェブアプリケーション**
   - **承認済みの JavaScript 生成元** に `https://<ユーザー名>.github.io` を追加（パスは付けない）
   - 手元で試す場合は `http://localhost:8000` も追加
5. 表示された「クライアントID」（`…apps.googleusercontent.com`）をコピー

## 3. アプリで接続する

1. 公開したURLを開くと設定画面が出るので、クライアントIDを貼り付け
2. **「Googleに接続して同期」** → Googleのログイン画面で許可
   （テスト中アプリの警告が出たら「続行」）
3. 他の端末でも同じURLを開いて、同じGoogleアカウントで接続すれば同期されます

クライアントIDを毎回入力したくない場合は、`index.html` 冒頭の `DEFAULT_CLIENT_ID = ''` に書き込んでから公開してください。

スマホでは、ブラウザの「ホーム画面に追加」でアプリのように使えます。

## 4. Webクリップの設定

クリップした記事は「Webクリップ」ノートブックに入ります。記事本文と画像、元ページへのリンクが保存されます。
ブックマークレットとショートカット用のコードは、アプリの **設定 → Webクリップ** にあり、「コピー」で取得できます（アプリのURLは自動で埋め込まれます）。

**先にやっておくと楽なこと**：`index.html` の `DEFAULT_CLIENT_ID` にクライアントIDを書いておく。
クリップはブラウザ側のNoteBoxに届くため、端末ごとにクライアントIDを入れる手間が省けます。

### iPhone（Safariの共有ボタンから・本文ごと保存）

iPhoneでは、Webアプリを共有ボタンの送り先に直接出せないため、「ショートカット」アプリで共有ボタン用のショートカットを作ります。記事の本文はクリップボード経由でNoteBoxに渡します（URLに載せると長すぎて「URLを開く」が受け付けないため）。

1. iPhoneの **設定 → アプリ → ショートカット → 詳細** で「**JavaScriptの実行を許可**」をオン
2. **ショートカット** アプリで「＋」→ 新規ショートカット
3. アクション「**Webページで JavaScript を実行**」を追加し、中身を全部消して、NoteBoxの設定画面でコピーした「① JavaScriptのアクションに貼り付けるコード」を貼り付け
4. アクション「**クリップボードにコピー**」を追加（入力は「JavaScriptの結果」のまま）
5. アクション「**URLを開く**」を追加し、URL欄にNoteBoxの設定画面でコピーした「② 『URLを開く』アクションに入れるURL」（`…/notebox/#clip=paste`）を貼り付け
6. 名前を「NoteBoxにクリップ」などにし、ⓘ（詳細）で「**共有シートに表示**」をオン
7. Safariで記事を開き、**共有ボタン → NoteBoxにクリップ**（初回はサイトへのアクセス許可を聞かれるので「許可」）
8. NoteBoxが開いたら、上に出る「**クリップを保存**」→ 表示される「**ペースト**」を押す

文章を選択した状態で共有すると、選択部分だけをクリップします。以前の2アクション版（「URLを開く」に「JavaScriptの結果」を渡すもの）は、長い記事で「有効なURLが渡されていることを確認してください」と出るため、作り直してください。

> **iPhoneの注意**：ホーム画面に追加したNoteBoxと、Safariで開くNoteBoxは、端末内の保存場所が別々です。クリップはSafari側に届くので、**Safariで開いたNoteBoxでもGoogleに接続**しておいてください。クリップ後に「ドライブに送る」が出たらタップすると同期され、ホーム画面側のNoteBoxにも反映されます。

### Androidタブレット

**共有メニューから（URL・タイトル・選択した文章を保存）**
1. ChromeでNoteBoxを開き、メニュー（︙）→「**アプリをインストール**」（または「ホーム画面に追加」）
2. 以後、Chromeなど各アプリの **共有 → NoteBox** で保存できます

**本文ごと保存したいとき（ブックマークレット）**
1. Chromeで適当なページをブックマーク（☆）→ 編集で、名前を「クリップ」、URLをNoteBoxの設定画面でコピーした「ブックマークレット」に置き換え
2. 記事を開いた状態でアドレスバーに「クリップ」と入力し、候補に出る★付きの「クリップ」をタップ

### クリップの制限

- 記事中の画像は元サイトの画像を表示しているだけなので、元ページが消えたりオフラインだったりすると表示されません（本文の文字は残ります）
- ログインが必要なページも、表示できていればクリップできます
- サイトの作りによっては本文の判定がずれることがあります。その場合は文章を選択してからクリップしてください
- 非常に長いページは、画像なしの文字だけで保存されます

## 5. 他のアプリからの取り込み

**左メニュー下の「ノートの取り込み」** で、NoteBox用の取り込みファイル（.zip）を選ぶと、ノートと添付ファイルをまとめて追加できます。

- 取り込んだノートは、取り込みファイルで指定されたノートブック（Evernoteの場合は「Evernote」）に入ります
- 作成日・更新日・タグも引き継がれます
- 同じファイルを2回取り込んでも、取り込み済みのノートはスキップされます
- ドライブへの送信は通常の同期で順に行われます。左下の表示が「同期中… 添付 ○/○」になっている間は、アプリを開いたままにしてください。途中で閉じても、次に開いたときに続きから送ります
- 添付が多い場合はPCでの取り込みがおすすめです（他の端末では、開いたノートの画像から順に読み込まれます）
- 取り込み用の部品をインターネットから読み込むため、取り込み時はオンラインで行ってください

## 使い方メモ

- **保存**：入力は自動保存（端末内）→ 数秒後にドライブへ同期。ノート一覧の黄色い●は未同期の印
- **オフライン**：圏外でも閲覧・編集・添付ができ、つながったときに同期
- **再接続**：Googleのログインは約1時間で切れます。左下の同期表示が「タップして再接続」になったらタップ（同意済みなら一瞬で戻ります）
- **同期で届いたノート**：他の端末から届いたノートやタグ・ノートブックは、受信が終わってから一覧にまとめてポップインで表示されます（一覧が見えていないときは、次に見えたときに表示）
- **同期の通信量**：同期のたびに、前回からドライブで変更があったファイルだけを問い合わせます（変更がなければ1回・約1KBの通信）。設定の「Googleに接続して同期」を押したときと、12時間ごとには全体を確認し直します
- **競合**：2台で同時に同じノートを編集した場合は、片方を「（競合コピー）」として残します。競合コピーを開くと上部に「元のノートと見比べてまとめる」が出るので、違う箇所ごとに「元のノート／競合コピー／両方」を選んで、元のノートに1つにまとめられます（競合コピーはゴミ箱へ）
- **過去の版との違い**：「⋯」→「過去の版」で版を選ぶと、今の内容との違いを色分けして表示します（緑＝今ある、赤＝その版にだけある、黄色の枠＝書き換えた段落で、変わった文字に印）。「この版の内容」に切り替えると、その版をそのまま表示します
- **削除**：🗑でゴミ箱へ。ゴミ箱から「完全に削除」すると、ドライブ側でもゴミ箱へ移動（30日間は復元可）
- **ピン留め**：ノート右上のピンで固定すると、左メニューの「すべてのノート」の上に並び、すぐ開けます（他の端末にも同期）
- **パネル幅**：左メニュー・ノート一覧・本文の境目をドラッグすると幅を変えられます（ダブルクリックで元の幅に戻る）
- **大きく表示**：ノート左上の矢印ボタンで本文だけを大きく表示。もう一度押すか Esc で元に戻ります（PC・横向きタブレット）
- **タグ**：「＋ タグ」を押して入力し Enter で追加（「#」は不要、候補も出ます）。タグをタップすると外すか選べます。入力欄が空のときにバックスペースを2回押すと最後のタグを外せます
- **表の色**：表の中をタップすると出る表バーの「色」から、濃い緑・薄い緑・色なしを選べます。「範囲」ボタンでセル／行／列を切り替え（PCでは複数セルを選択してまとめて塗ることも可能）
- **画像の大きさ**：画像をタップすると、小・中・大・幅いっぱい・元のサイズのボタンが出ます。右下の丸をドラッグすると自由な大きさに変えられます
- **元に戻す・やり直す**：ツールバー左端の ↶ ↷（PCでは Ctrl+Z / Ctrl+Shift+Z も可）。🕘 で操作履歴を一覧表示し、選んだ時点に戻せます。履歴はノートを開いている間だけ保持されます
- **表のコピー**：表バーの「表を選択」「表をコピー」「表を複製」。コピーした表は別のノートにもそのまま貼り付けられます（色も保持）。Excel・Googleスプレッドシート・Webページの表を貼り付けても表になります
- **ハイライト**：文字を選んでツールバーの「🖍 ハイライト」→ 黄・緑・ピンク。ハイライトの中で押すと「ハイライトを消す」
- **コメント**：文字を選んで「💬 コメント」。コメントの付いた文字（点線の下線）をタップすると内容が表示され、編集・削除できます。右上の💬で一覧を表示。コメントの内容も検索の対象です
- **ドラッグで移動**：ノート一覧のノートを左のノートブックへドラッグすると移動、タグへドラッグするとタグ付け、ピン留め欄へドラッグするとピン留め、ゴミ箱へドラッグすると確認のあと削除。タッチ操作では長押ししてからドラッグ（縦向きでは左メニューが自動で開きます）
- **複数選択**：一覧上部の「選択」で、まとめて移動・タグ・ピン・ゴミ箱へ。PCでは Ctrl/⌘＋クリック、Shift＋クリックでも選べます
- **並べ替えと表示**：ノート一覧上部の ⇅ で、更新日・作成日・タイトル順の並べ替えと、詳細／コンパクト／カード（画像付き）の表示を切り替え（端末ごとに記憶）
- **複製**：「⋯」→「ノートを複製」、または複数選択から「複製」
- **アーカイブ**：「⋯」→「アーカイブへ移動」、複数選択の「アーカイブ」、左メニューの「アーカイブ」へドラッグ。一覧からは外れますが、検索には出ます。左メニューの「アーカイブ」から確認・戻せます
- **入力ショートカット**：行頭で「## 」→見出し（#の数で1〜4）、「- 」→箇条書き、「1. 」→番号付き、「[] 」→チェックリスト、「> 」→引用、「---」＋Enter→区切り線（全角の＃・＞も可）。行頭やスペースの後で「/」（全角「／」も可）を打つと挿入メニューが出ます（続けて「ひょう」などと打つと絞り込み）
- **別のウィンドウで開く**：ノート上部の ⧉ ボタン（または「⋯」）で、そのノートを本文だけの別ウィンドウで開けます。どちらで編集しても、もう一方にすぐ反映されます。ドライブとの同期はメインの画面が行います。別ウィンドウ上部の「✕ 閉じる」で閉じ、「メイン画面で開く」でメインの画面にそのノートを表示します（閉じられない環境では、自動でメインの画面に戻ります）
- **構成ボード**：「⋯」→「構成ボード」。見出しごとにカードが並び、ドラッグ（タッチは長押しから）や ↑↓ で並べ替えると本文の順番も入れ替わります（下位の見出しや本文も一緒に移動）。カードの単位は見出し1〜3から選択
- **一覧の開閉**：左メニューの「ピン留め」「ノートブック」「タグ」の見出しを押すと、それぞれの一覧を開閉できます。左上の「すべて閉じる／すべて開く」で、ノートブックの階層も含めてまとめて開閉。閉じた状態は端末ごとに記憶されます。ノートをドラッグ中に閉じた見出しの上で少し待つと自動で開きます
- **ノートブックの階層**：ノートブックの「⋯」→「この中にノートブックを作る」「別のノートブックの中へ移動」。ノートブックをドラッグして別のノートブックに重ねても入れ子にできます（「ノートブック」見出しに落とすと最上位へ）。▼で折りたたみ
- **目次と文字数**：ノート上部の「○○字」を押すと、見出しの目次と見出しごとの文字数、原稿用紙換算の枚数が出ます（文字を選ぶと選択範囲の字数も表示）
- **検索と置換**：「⋯」→「検索と置換」（PCは Ctrl+F / Ctrl+H）。「全ノートで」にチェックすると全ノート一括で置換でき、直後なら元に戻せます
- **ノート間リンク**：本文で [[ と入力すると候補が出て、選ぶとそのノートへのリンクになります（ツールバーの「🔗 リンク」からも可）。リンクされたノートの下部に「このノートを参照しているノート」が表示されます
- **テンプレート**：「⋯」→「テンプレートとして保存」。一覧上部の 📋 からテンプレートを選んで新規作成。本文やタイトルの {{日付}} {{時刻}} は作成時の日時に置き換わります
- **過去の版**：「⋯」→「過去の版」で、Googleドライブに残っている保存履歴から以前の状態を確認・復元できます（ドライブの仕組みで約30日・100件まで）
- **書き出し**：「⋯」→「書き出す」で Word（.doc）・Markdown・PDF（印刷画面で「PDFに保存」）。設定の「全ノートをバックアップ（zip）」は添付込みで、取り込みからそのまま戻せます。「全ノートをMarkdownで書き出し」はノートブックごとのフォルダに分かれます
- **縦書きで読む**：「⋯」→「縦書きで読む」。明朝／ゴシック、文字サイズを切り替えられます
- **再接続の自動化**：Googleの接続が切れていたら、次に画面をタップしたときに自動で再接続します（設定でオフにできます）
- **Claude共有**：ノート上部の「Claude共有」を押すと、Googleドライブの「NoteBox/Claude共有」フォルダに、そのノートの写し（Googleドキュメント、名前はノートのタイトル）が作られます。ノートを編集すると写しも自動で更新されます（入力のたびには送らず、そのノートを閉じたときか、最後の編集から5分たったときにまとめて更新）。Claudeによる写しの修正は、そのノートを開いたときと通常の同期で確認します。Claudeに「NoteBoxの『〇〇』を読んで」と頼むと、この写しを読めます。もう一度押すとオフになり、写しは削除されます（複数選択からもまとめて切り替え可能）
- **Claudeの修正を取り込む**：Claudeが写しのGoogleドキュメントを直接修正した場合、次の同期で「〇〇（Claude修正版）」という新しいノートとして保存されます（タグ「Claude修正版」付き）。元のノートはそのままで、写しは元のノートの内容に戻ります。画像・添付・ノート間リンク・コメントは目印（【画像：…】など）を通じて元に戻ります
- **Claudeの修正JSON**：どの会話・プロジェクトでも、Claudeに「NoteBoxの『〇〇』を整形して」と頼むと（スキル「notebox-revision」）、修正JSONが出てきます。左メニュー下の「ノートの取り込み」 で「取り込みファイルを選ぶ」（ファイルの場合）か「テキストを貼り付けて取り込む」（テキストの場合）で読み込むと、「〇〇（Claude修正版）」ノートが作られます。「元のノートを書き換えて」と頼んだ場合は元のノートが書き換わり、直後の「元に戻す」で戻せます
- **スマホでの操作**：画面幅が狭いときは、ピン留め・ゴミ箱・Claude共有・別ウィンドウはノート右上の「⋯」メニューにまとまっています
- **検索**：タイトル・本文・タグ・ノートブック名を対象。スペース区切りでAND検索
- **チェックリスト**：☑︎ボタンで作成。行頭の□をタップで完了／未完了
- **画像**：1.5MBを超える写真は自動で長辺2048pxに縮小して保存。ノートを開くと、画面に近い画像から順に読み込みます。大きな画像は端末内では表示用の縮小版（長辺1600px、カード表示用は400px）だけを持ち、元の画像はドライブに残ります（書き出し時などは元の画像を取り直します）
- **容量の整理**：設定 →「使われていない添付ファイルを整理」で、削除したノートなどに付いていた不要な画像・添付ファイルをドライブのゴミ箱へ移します（作成から3日以内のもの・ゴミ箱のノートの画像は残します。ドライブのゴミ箱から30日間は復元可能）
- **バックアップ**：設定 →「バックアップを書き出す」でノート本文をJSONで保存（添付ファイルはドライブの `NoteBox/attachments` に実体あり）

## 注意点

- ドライブの `NoteBox` フォルダ内のファイルは手で編集・移動しないでください（同期が崩れます）
- アプリの権限は `drive.file`（このアプリが作ったファイルだけ）なので、ドライブの他のファイルには一切触れません
- ノートから消した添付ファイルは `attachments` フォルダに残ります（容量が気になったら手動で削除）
- iPhoneで「ホーム画面に追加」したアプリからだとログイン画面がうまく戻らないことがあります。その場合は一度Safariで開いて接続してください
- アプリを更新（ファイルを差し替え）した場合、各端末では次に開いたときに新しい版になります。左上の「NoteBox」を押すと、今の版・更新履歴と「最新版に更新」ボタンが表示されます

## データ構造（参考）

```
マイドライブ/NoteBox/
├── notebooks.json        … ノートブック一覧
├── note-<ID>.json        … ノート1件ごと（タイトル・本文HTML・タグ等）
└── attachments/          … 画像・添付ファイル
```

```
cd notebox
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
